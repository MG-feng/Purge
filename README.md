# 《Purge》

A fast-paced survival shooter game. Fight hordes of enemies across a vast map, gather resources, buy weapons and abilities, and take on increasingly powerful foes.

## Features

- Multiple weapons: Pistol, Rifle, Sniper, Soul Reaper, Laser Gun, and more
- Rich ability system: Mix active and passive skills
- Throwable system: Grenades, beacons, and other tactical items
- Multiple difficulty modes: Easy, Medium, Hard, Endless, Boss Rush
- Permanent progression: Purchase weapons and abilities in the shop to grow stronger

**Survive until the very last moment!**
