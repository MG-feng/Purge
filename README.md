# 《Purge》

[![License](https://img.shields.io/badge/License-CC%20BY%204.0-blue.svg)](https://creativecommons.org/licenses/by/4.0/)
[![Version](https://img.shields.io/badge/version-v0.3.X%20Alpha-orange.svg)](https://github.com/MG-feng/Purge)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey.svg)]()

**《Purge》** 一款快节奏的生存射击游戏。在广阔的地图中与潮水般的敌人战斗，收集资源，购买武器和技能，挑战越来越强的敌人。

**《Purge》** is a fast-paced survival shooter game. Fight hordes of enemies across a vast map, gather resources, buy weapons and abilities, and take on increasingly powerful foes.

## ✨ 特色 / Features

| 中文 | English |
|------|---------|
| 多种武器：手枪、步枪、狙击枪、灵魂收割者、激光枪等 | Multiple weapons: Pistol, Rifle, Sniper, Soul Reaper, Laser Gun, and more |
| 丰富的技能系统：主动技能与被动技能搭配 | Rich ability system: Mix active and passive skills |
| 投掷物系统：手雷、beacon 等战术道具 | Throwable system: Grenades, beacons, and other tactical items |
| 多难度模式：简单、普通、困难、无尽、Boss Rush | Multiple difficulty modes: Easy, Medium, Hard, Endless, Boss Rush |
| 永久成长：通过商店购买武器和技能，累积财富 | Permanent progression: Purchase weapons and abilities to accumulate wealth |

**生存下去，直到最后一刻！** | **Survive until the very last moment!**

## 📋 配置要求 / System Requirements

### 最低配置（可一定程度上流畅运行）/ Minimum Requirements (Smooth playable to some extent)

| 项目 / Component | 要求 / Requirement |
|-----------------|--------------------|
| CPU | 2 线程，1.5 GHz / 2 cores, 1.5 GHz |
| GPU | 10W，1 GB |
| 内存 / RAM | 2 GB |
| 磁盘空间 / Disk Space | 400 MB |
| 操作系统 / OS | Windows 8 64-bit / macOS 10.14 |
| 网络 / Network | 离线 / Offline |
| 显卡驱动 / Graphics Driver | 支持 OpenGL 2.1+ 或 DirectX 11 / OpenGL 2.1+ or DirectX 11 support |

### 推荐配置（无卡顿）/ Recommended Requirements (No lag)

| 项目 / Component | 要求 / Requirement |
|-----------------|--------------------|
| CPU | 4 线程，2.0 GHz / 4 cores, 2.0 GHz |
| GPU | 20W，2 GB |
| 内存 / RAM | 3 GB |
| 磁盘空间 / Disk Space | 750 MB（推荐 SSD / SSD recommended） |
| 操作系统 / OS | Windows 10 64-bit / macOS 12+ |
| 网络 / Network | 离线 / Offline |
| 显卡驱动 / Graphics Driver | 支持 OpenGL 4.5+ 或 DirectX 12 / OpenGL 4.5+ or DirectX 12 support |
